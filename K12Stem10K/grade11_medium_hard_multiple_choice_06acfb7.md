# Chemistry - 题目 645

**ID**: 06acfb7ba84e4c4b8ccd517d286242b8
**年级**: Grade 11
**难度**: Medium-Hard
**题型**: 非选择题

## 题目
某化学研究性学习小组讨论 ${\rm{F}}{\rm{e}}^{3+}$ 和 ${\rm{S}}{\rm{O}}_{3}^{2-}$ 之间会发生怎样的反应，提出了两种可能：一是发生氧化还原反应 $2{\rm{F}}{\rm{e}}^{3+}+{\rm{S}}{\rm{O}}_{3}^{2-}+{\rm{H}}_{2}{\rm{O}}{\rm{=}}2{\rm{F}}{\rm{e}}^{2+}+{\rm{S}}{\rm{O}}_{4}^{2-}+2{\rm{H}}^{+}$ ；二是发生相互促进的水解反应 $2{\rm{F}}{\rm{e}}^{3+}+3{\rm{S}}{\rm{O}}_{3}^{2-}+6{\rm{H}}_{2}{\rm{O}}\rightleftharpoons 2{\rm{F}}{\rm{e}}\left ({{\rm{O}}{\rm{H}}}\right )_{3}\left ({胶体}\right )+3{\rm{H}}_{2}{\rm{S}}{\rm{O}}_{3}$ 。​​​​​​​‌为了证明发生的是哪一种反应，同学们设计并实施了以下实验，请填写下列空白。实验Ⅰ  学生选择的实验用品有 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 浓溶液、 ${\rm{B}}{\rm{a}}{\rm{C}}{\rm{l}}_{2}$ 稀溶液、稀盐酸；试管若干、胶头滴管若干。从选择的药品分析，设计这个实验的目的是。实验Ⅱ  取 $5{\rm{m}}{\rm{L}}{\rm{\;}}{\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}_{3}$ 浓溶液于试管中，逐滴加入 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 浓溶液，观察到溶液由黄色变为红棕色，无气泡产生，无沉淀生成，继续加入 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 浓溶液至过量，溶液颜色加深，最终变为红褐色。这种红褐色液体是。向红褐色液体中逐滴加入稀盐酸至过量，可以观察到的现象是。将溶液分成两等份，其中一份加入 ${\rm{K}}{\rm{S}}{\rm{C}}{\rm{N}}$ 溶液，溶液变成血红色，反应的离子方程式为；另一份加入 ${\rm{B}}{\rm{a}}{\rm{C}}{\rm{l}}_{2}$ 稀溶液，有少量白色沉淀生成，产生该白色沉淀的离子方程式为。实验Ⅲ  换用稀释的 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}_{3}$ 溶液和 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 溶液重复实验Ⅱ，产生的现象完全相同。由上述实验得出的结论是。若在 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}_{3}$ 浓溶液中加入 ${\rm{N}}{\rm{a}}_{2}{\rm{C}}{\rm{O}}_{3}$ 浓溶液，观察到有红褐色沉淀生成并且产生无色气体，该反应的离子方程式是。从形式上看， ${\rm{N}}{\rm{a}}_{2}{\rm{C}}{\rm{O}}_{3}$ 和 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 相似，但是从上述实验中可以看到，二者的水溶液与氯化铁溶液反应的现象差别很大，其原因可能是①；②。

## 解答

1. 实验Ⅰ中，学生选择的实验试剂为 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 浓溶液、 ${\rm{B}}{\rm{a}}{\rm{C}}{\rm{l}}_{2}$ 稀溶液、稀盐酸，目的是检验亚硫酸钠是否被氧化成了硫酸钠。
2. 实验Ⅱ中，取 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}_{3}$ 浓溶液于试管中，观察到溶液由黄色变为红棕色，无气泡产生，无沉淀生成，继续加入Na_{2}SO_{3}浓溶液至过量，溶液颜色加深，最终变为红褐色。向红褐色液体中逐滴加入稀盐酸至过量，将溶液分成两等份，其中一份加入KSCN溶液，溶液变成血红色，说明FeCl_{3}和Na_{2}SO_{3}反应生成的铁有+3价，说明发生了相互促进的水解反应；另一份加入BaCl_{2}稀溶液，有少量白色沉淀生成，说明有 ${\rm{S}}{\rm{O}}_{4}^{2-}$ 生成，说明发生了氧化还原反应。这说明FeCl_{3}和Na_{2}SO_{3}反应既发生了双水解反应，生成了Fe(OH)_{3}胶体和亚硫酸，又发生了氧化还原反应，生成了Fe^{2+}和 ${\rm{S}}{\rm{O}}_{4}^{2-}$ 。向胶体中逐滴加入稀盐酸，胶体发生聚沉，盐酸过量时，可以和氢氧化铁发生酸碱中和反应，生成FeCl_{3}溶液，观察到沉淀溶解，溶液变为黄色，过量的盐酸还可以和过量的Na_{2}SO_{3}反应生成SO_{2}气体，故还可以观察到有气泡产生。向加入过量盐酸的溶液中加入 ${\rm{K}}{\rm{S}}{\rm{C}}{\rm{N}}$ 溶液，溶液变为血红色，反应的离子方程式为 ${\rm{F}}{\rm{e}}^{3+}+3{\rm{S}}{\rm{C}}{\rm{N}}^{-}$ = Fe(SCN)_{3}。由于稀盐酸过量，故加入 ${\rm{B}}{\rm{a}}{\rm{C}}{\rm{l}}_{2}$ 稀溶液后生成的白色沉淀为硫酸钡，反应的离子方程式为 ${\rm{B}}{\rm{a}}^{2+}+{\rm{S}}{\rm{O}}_{4}^{2-}$ = BaSO_{4}↓。
3. 实验Ⅲ中，换用稀释的 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}_{3}$ 溶液和 ${\rm{N}}{\rm{a}}_{2}{\rm{S}}{\rm{O}}_{3}$ 溶液重复实验Ⅱ，产生的现象完全相同，证明 ${\rm{F}}{\rm{e}}^{3+}$ 与 ${\rm{S}}{\rm{O}}_{3}^{2-}$ 发生的氧化还原反应和相互促进的水解反应是同时进行的。在 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}_{3}$ 浓溶液中加 ${\rm{N}}{\rm{a}}_{2}{\rm{C}}{\rm{O}}_{3}$ 浓溶液，观察到有红褐色沉淀生成并且产生无色气体，说明 ${\rm{F}}{\rm{e}}^{3+}$ 与 ${\rm{C}}{\rm{O}}_{3}^{2-}$ 发生了相互促进的水解反应，反应的离子方程式为 $2{\rm{F}}{\rm{e}}^{3+}+3{\rm{C}}{\rm{O}}_{3}^{2-}+3{\rm{H}}_{2}{\rm{O}}$  = 2Fe(OH)_{3}↓+3CO_{2}↑。Na_{2}CO_{3}和Na_{2}SO_{3}相似，但二者的水溶液与氯化铁溶液反应的现象差别很大，其原因可能是 ${\rm{S}}{\rm{O}}_{3}^{2-}$ 有较强的还原性， ${\rm{C}}{\rm{O}}_{3}^{2-}$ 没有还原性，还有可能是 ${\rm{S}}{\rm{O}}_{3}^{2-}$ 的水解能力较 ${\rm{C}}{\rm{O}}_{3}^{2-}$ 弱，所以二者只发生相互促进的水解反应，而没有发生氧化还原反应。
