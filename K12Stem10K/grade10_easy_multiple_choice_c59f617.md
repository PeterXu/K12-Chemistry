# Chemistry - 题目 889

**难度**: Easy
**题型**: Multiple-choice

## 题目
下列实验操作，现象及结论都正确的是选项实验操作和现象结论​​​​​​​‌

## 解答

1. A．实验中发生反应： ${\rm {\rm{C}}{\rm{u}}{\rm{+}}{\rm{2}}{\rm{F}}{\rm{e}}{^{{\rm{3}}{\rm{+}}}}{\rm{=}}{\rm{2}}{\rm{F}}{\rm{e}}{^{{\rm{2}}{\rm{+}}}}{\rm{+}}{\rm{C}}{\rm{u}}{^{{\rm{2}}{\rm{+}}}}}$ ，说明氧化性： ${\rm {\rm{C}}{\rm{u}}{^{2+}}{\rm{<}}{\rm{F}}{\rm{e}}{^{3+}}}$ ，但还原性即为金属活动性，因此还原性应为： ${\rm {\rm{C}}{\rm{u}}{\rm{<}}{\rm{F}}{\rm{e}}}$ ，A错误；
2. B．向40mL沸水中滴加5-6滴 ${\rm {\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}{{}_{3}}}$ 饱和溶液，继续煮沸至液体呈红褐色，停止加热，制得的为 ${\rm {\rm{F}}{\rm{e}}\left ({{\rm{O}}{\rm{H}}}\right ){{}_{{\rm{3}}}}}$ 胶体，B正确；
3. C．火焰颜色为黄色说明含有Na元素，但不一定为NaOH，也可以为碳酸钠或者碳酸氢钠，C错误；
4. D．向待测溶液中滴加氯水，可以将 ${\rm {\rm{F}}{\rm{e}}{^{2+}}}$ 氧化为 ${\rm {\rm{F}}{\rm{e}}{^{3+}}}$ ，因此滴加 ${\rm {\rm{K}}{\rm{S}}{\rm{C}}{\rm{N}}}$ 溶液，溶液变红，不能说明该待测溶液中一定含有 ${\rm {\rm{F}}{\rm{e}}{^{3+}}}$ ，D错误；
5. 故选B。
