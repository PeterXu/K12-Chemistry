# Chemistry - 题目 1784

**题型**: Multiple-choice

## 题目
下列说法正确的是（      ）​​​​​​​‌

## 解答

1. A、红磷燃烧生成五氧化二磷固体小颗粒，这些固体小颗粒分散在空气中形成白烟，而白雾是小液滴悬浮在空气中形成的。所以红磷燃烧产生的是大量白烟，不是白雾，错误；
2. B、做木炭在氧气中燃烧实验时，若将红热的木炭迅速放入集气瓶底部，木炭燃烧产生的热量会使氧气受热逸出，不利于木炭与氧气充分接触并持续燃烧，应将红热的木炭由瓶口向下缓慢伸入集气瓶中，错误；
3. C、铁在氧气中燃烧，集气瓶底预留少量水是为了防止高温熔融物溅落炸裂瓶底；硫在氧气中燃烧，集气瓶底预留少量水是为了吸收生成的二氧化硫有害气体，防止污染空气，二者目的不同，错误；
4. D、一氧化碳具有可燃性，燃烧时会放出大量的热，火焰呈蓝色，正确。
