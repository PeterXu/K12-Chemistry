# Chemistry - 题目 440

## 题目
下列除杂的操作方法正确的是①NO中有少量的 ${\rm {\rm{N}}{\rm{O}}{{}_{{\rm{2}}}}}$ ：用水洗涤后再干燥②食盐中有少量的 ${\rm {\rm{N}}{\rm{H}}{{}_{{\rm{4}}}}{\rm{C}}{\rm{l}}}$ ：加过量的烧碱溶液后加热蒸干③ ${\rm {\rm{N}}{\rm{O}}{{}_{{\rm{2}}}}}$ 中有少量的NO：通入过量的氧气④ ${\rm {\rm{C}}{\rm{O}}{{}_{{\rm{2}}}}}$ 中混有少量的 ${\rm {\rm{S}}{\rm{O}}{{}_{{\rm{2}}}}}$ 气体：通过饱和 ${\rm {\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{\rm{3}}}}}$ 溶液洗气​​​​​​​‌

## 解答

1. ①NO_{2}与水反应生成NO，除去NO中混有的NO_{2}，可用水洗涤后再干燥，正确；
2. ②加入过量的烧碱会引入新杂质，错误；
3. ③通如入过量的氧气会引入杂质，错误；
4. ④二氧化硫能与饱和碳酸氢钠溶液反应生成二氧化碳，可用此方法除去 ${\rm {\rm{C}}{\rm{O}}{{}_{{\rm{2}}}}}$ 中混有少量的 ${\rm {\rm{S}}{\rm{O}}{{}_{{\rm{2}}}}}$ 气体，正确；
5. 故选C。
