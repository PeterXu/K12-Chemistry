# Chemistry - 题目 2282

## 题目
向氧化铜和铁粉的混合物中加入一定量的稀硫酸，微热，充分反应后过滤，向滤液中插入一个铁片，有气泡产生。​​​​​​​‌下列表判断正确的是

## 解答

1. A、铁与稀硫酸反应生成硫酸亚铁和氢气，说明滤液中一定含有硫酸亚铁，判断正确；
2. B、向滤液中插入一个铁片，有气泡产生，说明滤液中一定含有硫酸，而氧化铜和硫酸反应生成的硫酸铜还会与铁反应，由于硫酸剩余则铁完全反应，因此无法说明铁和硫酸铜的反应情况，则硫酸铜应为可能有不是一定含有，判断错误；
3. C、向滤液中插入一个铁片，有气泡产生，说明滤液中一定含有硫酸，铁能和硫酸反应因此滤出的固体没有铁，判断错误；
4. D、向滤液中插入一个铁片，有气泡产生，说明滤液中一定含有硫酸，氧化铜能和硫酸反应生成硫酸铜和谁，因此滤出的固体没有氧化铜，判断错误；
5. 故选A。
