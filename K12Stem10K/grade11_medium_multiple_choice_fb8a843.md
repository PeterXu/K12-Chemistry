# Chemistry - 题目 1374

**题型**: Multiple-choice

## 题目
下列各选项描述的两种不同情境，一定不可以用同一化学方程式或离子方程式表示的（      ）​​​​​​​‌

## 解答

1. A．Fe(NO_{3})_{2}溶液中滴加稀硫酸时，H^{+}与NO_{3}^{-}形成HNO_{3}，氧化Fe^{2+}；FeSO_{4}中滴加稀硝酸时，H^{+}和NO_{3}^{-}同样氧化Fe^{2+}。两者均生成Fe^{3+}、NO和H_{2}O，离子方程式相同。A不符合题意；
2. B．Cl_{2}与NaOH或Ca(OH)_{2}溶液反应，均生成Cl^{-}和ClO^{-}，离子方程式均为Cl_{2}+ 2OH^{-}= Cl^{-}+ ClO^{-}+ H_{2}O。B不符合题意；
3. C．纯碱（Na_{2}CO_{3}）与CaSO_{4}反应生成CaCO_{3}和Na_{2}SO_{4}；石膏（CaSO_{4}）与盐碱地中的Na_{2}CO_{3}反应同样生成CaCO_{3}和Na_{2}SO_{4}，化学方程式相同。C不符合题意；
4. D．FeBr_{2}中Cl_{2}少量时优先氧化Fe^{2+}（2Fe^{2+}+ Cl_{2}= 2Fe^{3+}+ 2Cl^{-}），而FeI_{2}中Cl_{2}少量时优先氧化I^{-}（2I^{-}+ Cl_{2}= I_{2}+ 2Cl^{-}），离子方程式不同。D符合题意；
5. 答案选D。
