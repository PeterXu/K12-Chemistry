# Chemistry - 题目 2614

**题型**: Multiple-choice

## 题目
下列实验方案中，不能测定 ${\rm{N}}{\rm{a}}{{}_{2}}{\rm{C}}{\rm{O}}{{}_{3}}$ 和 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{3}}$ 混合物中 ${\rm{N}}{\rm{a}}{{}_{2}}{\rm{C}}{\rm{O}}{{}_{3}}$ 质量分数的是（      ）​​​​​​​‌

## 解答

1. A．取 ${\rm a}$ 克混合物充分加热，减重 ${\rm b}$ 克。减重 ${\rm b}$ 克为 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 分解生成的 ${\rm{C}}{\rm{O}}{{}_{2}}$ 和 ${\rm{H}}{{}_{{{2}}}}{\rm{O}}$ 的总质量(它们的物质的量都为 $\frac {bg}{\left ({44+18}\right )}=\frac {b}{62}$ )则根据化学方程式 $2NaHCO{{}_{3}}{\xrightarrow []{加热}}Na{{}_{2}}CO{{}_{3}}+{\rm{H}}{{}_{2}}{\rm{O}}+CO{{}_{2}}$ ，可计算 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 的物质的量为 $\frac {{\rm{b}}}{31}$ ，进而求出 ${\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 的质量分数，A不符合；
2. B．取 ${\rm a}$ 克混合物与足量稀盐酸反应，最终得到 ${\rm b}$ 克固体。通过 ${\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 和 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 生成NaCl的物质的量关系，可建立方程组求解两者质量，B不符合；
3. C．取 ${\rm a}$ 克混合物与稀硫酸反应，逸出气体被碱石灰吸收增重 ${\rm b}$ 克。碱石灰吸收的增重包含 ${\rm{C}}{\rm{O}}{{}_{2}}$ 和部分水蒸气，无法单独确定 ${\rm{C}}{\rm{O}}{{}_{2}}$ 质量，导致无法计算，C符合；
4. D．取 ${\rm a}$ 克混合物与 ${\rm{B}}{\rm{a}}\left ({{\rm{O}}{\rm{H}}}\right ){{}_{{{2}}}}$ 溶液反应，生成 ${\rm b}$ 克 $BaCO{{}_{3}}$ 沉淀，根据总碳守恒，可列方程组求解 ${\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 和 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 的质量，D不符合；
5. 故选C。
