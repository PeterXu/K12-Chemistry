# Chemistry - 题目 918

**题型**: Multiple-choice

## 题目
如图所示，将液体X加入到集气瓶中与固体Y作用，观察到气球逐渐变大，如表中液体X和固体Y的组合，符合题意的是（      ）①②③④⑤X稀盐酸水水双氧水水Y锌粒氢氧化钠氯化钠二氧化锰硝酸铵​​​​​​​‌

## 解答

1. ①稀盐酸与锌粒反应生成氢气，且反应放热，使得集气瓶中压强变大，气球逐渐变大。
2. ②氢氧化钠固体溶于水放出大量的热，集气瓶内温度升高，使得集气瓶中压强变大，气球逐渐变大。
3. ③氯化钠溶解于水，温度变化不明显，集气瓶中压强无明显变化，气球不会变大。
4. ④双氧水是过氧化氢溶液的俗称，在二氧化锰作催化剂时，迅速发生反应生成氧气、水，集气瓶中气体增多，压强变大，气球逐渐变大。
5. ⑤硝酸铵溶解于水，吸收大量的热，温度明显下降，集气瓶中压强变小，在大气压的作用下，气球逐渐变瘪。

## 知识点

**中文**:
  - 溶解时的热量变化
  - 过氧化氢制取氧气
  - 金属与酸反应

**English**:
  - Heat Changes during Dissolution
  - Preparation of Oxygen using Hydrogen Peroxide
  - Reaction of Metals with Acids
