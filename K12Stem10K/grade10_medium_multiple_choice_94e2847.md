# Chemistry - 题目 2893

## 题目
现有四种物质 ${\rm{H}}{\rm{C}}{\rm{l}}$ 、 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}{{}_{3}}$ 、 ${\rm{B}}{\rm{a}}({\rm{O}}{\rm{H}}){{}_{2}}$ 、 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{3}}$ ，它们之间的反应关系如图所示。​​​​​​​‌a、b、c、d代表这四种物质的溶液，e和f为沉淀，其中f为白色沉淀，g为气体。回答下列问题：(1)b代表的物质为(填化学式，下同)，d代表的物质为。(2)c中溶质的电离方程式为。(3)将a的饱和溶液分别滴入下列物质中加热，能形成胶体的是。

## 解答

1. （1）根据分析，b代表的物质为 ${\rm{B}}{\rm{a}}({\rm{O}}{\rm{H}}){{}_{2}}{\rm ，d}$ 代表的物质为 ${\rm{H}}{\rm{C}}{\rm{l}}$ 。
2. （2）c代表的物质为 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{3}}$ ，则电离方程式为 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}{\rm{=}}{\rm{N}}{\rm{a}}{^{{{+}}}}{{+}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}^{{{-}}}}$ 。
3. （3） ${\rm{F}}{\rm{e}}{\rm{(}}{\rm{O}}{\rm{H}}{\rm{)}}{{}_{{{3}}}}$ 胶体制备的方法是将少量饱和 ${\rm{F}}{\rm{e}}{\rm{C}}{\rm{l}}{{}_{3}}$ 溶液滴入沸水中，煮沸至液体呈红褐色，因此答案选B。
4. （4）c与d的反应为 ${\rm{N}}{\rm{a}}{\rm{H}}{\rm{C}}{\rm{O}}{{}_{3}}$ 与 ${\rm{H}}{\rm{C}}{\rm{l}}$ 复分解反应生成NaCl、 ${\rm{C}}{\rm{O}}{{}_{{{2}}}}$ 和水，离子方程式为 ${\rm{H}}{\rm{C}}{\rm{O}}{{}_{{{3}}}^{{{-}}}}{{+}}{\rm{H}}{^{{{+}}}}{\rm{=}}{\rm{C}}{\rm{O}}{{}_{{{2}}}}\uparrow {{+}}{\rm{H}}{{}_{{{2}}}}{\rm{O}}$ 。
5. （5）呼吸面具中常用的供氧剂是 ${\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{O}}{{}_{{{2}}}}$ ，为淡黄色固体； ${\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{O}}{{}_{{{2}}}}$ 与 ${\rm{C}}{\rm{O}}{{}_{{{2}}}}$ 反应生成 ${\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}$ 和氧气，化学方程式为 ${{2}}{\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{O}}{{}_{{{2}}}}{{+}}{{2}}{\rm{C}}{\rm{O}}{{}_{{{2}}}}{\rm{=}}{{2}}{\rm{N}}{\rm{a}}{{}_{{{2}}}}{\rm{C}}{\rm{O}}{{}_{{{3}}}}{{+}}{\rm{O}}{{}_{{{2}}}}$ 。
6. （6）向 ${\rm{B}}{\rm{a}}({\rm{O}}{\rm{H}}){{}_{2}}$ 溶液中逐滴加入稀硫酸至过量，生成 ${\rm{B}}{\rm{a}}{\rm{S}}{\rm{O}}{{}_{{{4}}}}$ 沉淀和水，则混合溶液中离子浓度降低，导电能力减弱至接近于零；当稀硫酸过量时，溶液中离子浓度增大，导电能力增强。
