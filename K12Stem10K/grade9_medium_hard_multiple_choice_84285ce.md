# Chemistry - 题目 1288

**题型**: Multiple-choice

## 题目
下列实验方案正确的是（      ）实验目的实验方法A除去KCl中的MnO_{2}溶解、过滤、洗涤、干燥B测定雨水的酸碱度滴加紫色石蕊溶液C鉴别硫酸钾和碳酸氢铵闻气味D分离四氧化三铁和铁粉用磁铁吸引​​​​​​​‌

## 解答

1. A、KCl易溶于水，MnO_{2}难溶于水，溶解、过滤、洗涤、干燥得到的是MnO_{2}而不是KCl，A错误；
2. B、紫色石蕊溶液遇酸变红遇碱变蓝，遇中性溶液不变色，所以紫色石蕊溶液只能测出雨水的酸碱性，而不能测出酸碱度，B错误；
3. C、硫酸钾没有气味，碳酸氢铵有氨味，可通过闻气味的方法鉴别硫酸钾和碳酸氢铵，C正确；
4. D、四氧化三铁和铁粉都有磁性，不能通过磁铁吸引的方式进行分离，D错误。
5. 故选：C。
